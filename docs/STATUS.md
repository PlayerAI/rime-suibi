# v0.3.0：词语首字笔画辅助

核查日期：2026-09-08。v0.3.0 新增词语首字笔画辅助，提供全拼、自然码与微软双拼三个独立安装包；未安装到实际用户目录。

- 三种方案支持完整多字词编码后输入反引号及首字笔顺；单字与反查行为保留。
- 复用唯一原生 `script_translator`，保留候选顺序、用户词库及选词学习。词语首字相同仍可重码。
- 仅筛选完整候选；不接受简拼、未完成音节或已经分段选定前缀。全拼自身为一个音节时优先单字模式，使用隔音符号区分“西安”等词。
- 方案 YAML 与 Lua 需一起更新，安装后重新部署；分发包及 SHA-256 清单位于 `dist/`。

核查日期：2026-09-06。三种方案及纯笔画反查已完成本地实现和引擎验证。

全拼、自然码双拼、微软双拼各有独立跨平台 ZIP，包含运行依赖数据及 GPL 源码。安装器按包内清单只安装和启用一个方案，也支持源码目录 `--scheme` 选择；多个方案可共存。

反查输入为反引号加五类笔画，覆盖 8105 字；8104 字有无声调拼音，多音字显示已有读音。“呣”可反查但提示读音未收录。双反引号输入一个字面符号。这是用户新增反查需求对 v0.1 单反引号输出符号行为的替代。
