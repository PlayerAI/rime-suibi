# v0.2.0 状态与验证

核查日期：2026-09-06。三种方案及纯笔画反查已完成本地实现和引擎验证。

全拼、自然码双拼、微软双拼各有独立跨平台 ZIP，包含运行依赖数据及 GPL 源码。安装器按包内清单只安装和启用一个方案，也支持源码目录 `--scheme` 选择；多个方案可共存。

反查输入为反引号加五类笔画，覆盖 8105 字；8104 字有无声调拼音，多音字显示已有读音。“呣”可反查但提示读音未收录。双反引号输入一个字面符号。这是用户新增反查需求对 v0.1 单反引号输出符号行为的替代。
